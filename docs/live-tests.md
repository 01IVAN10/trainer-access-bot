# Живі тести (перед запуском і після кожного великого оновлення)

Автотести (`python -m pytest`) перевіряють логіку з фальшивим Telegram і фальшивим банком.
Цей список — для справжнього Telegram і тестового режиму monobank: він ловить те, чого
фальшивки не знають (обмеження платформи, реальні затримки, як усе виглядає на телефоні).

Потрібно: бот запущений, два акаунти Telegram — **Власник** (у каналі й адмін-групі) і
**Клієнт** (сторонній акаунт, ще не в каналі). Тестова картка: `4242 4242 4242 4242`.
Демо-тариф (5 хв, `DEMO_MODE=1`) дає весь цикл за ~7 хвилин.

Позначки: ✅ — пройдено, дата; ❌ — що пішло не так.
